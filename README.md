## 🎮 About the Project

**Mario Bros — Pixel Adventure** is a 2D platform game developed in Python using the Pygame library.

The project recreates the classic platforming experience with pixel-art graphics, enemies, coins, obstacles and side-scrolling gameplay.

It is a personal project focused on learning and practicing programming, game logic and interactive development with Python.

## ✨ Features

- 🍄 Pixel-art graphics created with Python.
- 🏃 Player movement and jumping.
- 🐢 Enemies with collision detection.
- 🪙 Collectible coins and score system.
- 🧱 Blocks, platforms and pipes.
- ❤️ Life system.
- 🎥 Side-scrolling camera.
- 💀 Game Over system.

## 🕹️ Controls

| Action | Key |
|---|---|
| Move left | `←` or `A` |
| Move right | `→` or `D` |
| Jump | `SPACE`, `↑` or `W` |
| Restart after Game Over | `R` |
| Exit game | `ESC` |

## ⚙️ Requirements

Before running the game, make sure you have:

- Python installed.
- Pygame library.

## 🚀 Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/DavidSaavedraDev/Mario-bros.git
```

**2. Enter the project folder**

```bash
cd Mario-bros
```

**3. Install Pygame**

```bash
python -m pip install pygame
```

**4. Run the game**

```bash
python main.py
```
