## 🎮 ABOUT THE PROJECT

**Mario Bros 3D** es un proyecto de videojuego de plataformas que busca llevar la experiencia clásica de Mario a un entorno tridimensional.

El objetivo es construir un mundo colorido, interactivo y lleno de elementos que permitan explorar escenarios, saltar entre plataformas, recolectar monedas y enfrentarse a enemigos.

El proyecto se desarrolla utilizando **Godot Engine 4 y GDScript**, con especial atención al rendimiento y a una arquitectura organizada.

## 🚀 INSTALLATION

### Requirements

- Windows 10/11 de 64 bits.
- Godot Engine 4.
- Git (opcional).

### Clone repository

```bash
git clone https://github.com/DavidSaavedraDev/Mario-bros.git
```

### Open the project

1. Instala Godot Engine 4.
2. Abre Godot.
3. Selecciona Import.
4. Busca la carpeta del repositorio.
5. Selecciona `project.godot`.
6. Ejecuta el proyecto desde el editor.
